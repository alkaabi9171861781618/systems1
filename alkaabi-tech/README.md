# ALKAABI TECH — نظام إدارة طلبات الصيانة

هذا الدليل مكتوب لك حتى لو ما عندك أي خلفية برمجية. اتبع الخطوات بالترتيب وما راح تحتاج تكتب أي كود.

---

## الجزء الأول: التأسيس (تسويه مرة وحدة بس)

### الخطوة 1: تثبيت البرامج الأساسية على جهازك

1. حمّل وثبّت **Node.js** (النسخة LTS) من: https://nodejs.org
2. تأكد إنه انثبت صح: افتح "Terminal" أو "Command Prompt" واكتب:
   ```
   node -v
   ```
   إذا طلع رقم إصدار (مثلاً v20.x.x) يعني تمام.

### الخطوة 2: إنشاء مشروع Firebase (مجاني)

1. روح إلى https://console.firebase.google.com
2. اضغط **Add project** واكتب اسم المشروع (مثلاً `alkaabi-tech`)
3. بعد ما يخلص الإنشاء، من القائمة الجانبية:
   - افتح **Build → Authentication** → اضغط **Get started** → فعّل **Email/Password**
   - افتح **Build → Firestore Database** → اضغط **Create database** → اختر أي موقع قريب (مثلاً eur3) → ابدأ بوضع **production mode**
4. أنشئ حساب الأدمن (حسابك أنت):
   - بصفحة **Authentication → Users** اضغط **Add user**
   - اكتب بريدك الإلكتروني وكلمة مرور قوية — هذا هو الحساب اللي راح تسجل فيه دخول للوحة التحكم

### الخطوة 3: ربط المشروع بمفاتيح Firebase

1. بصفحة إعدادات المشروع (⚙️ بالأعلى) اضغط **Project settings**
2. تحت **Your apps** اضغط أيقونة الويب `</>` وسجّل تطبيق جديد (اسمه مثلاً "ALKAABI TECH Web")
3. راح يطلعلك كود فيه أرقام ونصوص مثل هذا:
   ```js
   const firebaseConfig = {
     apiKey: "...",
     authDomain: "...",
     projectId: "...",
     storageBucket: "...",
     messagingSenderId: "...",
     appId: "..."
   };
   ```
4. افتح ملف `.env.example` بمجلد المشروع، وسوّي نسخة منه باسم `.env` (نفس المحتوى بس بدون `.example`)
5. انسخ كل قيمة من الكود اللي طلع لك إلى `.env`، مثال:
   ```
   VITE_FIREBASE_API_KEY=AIzaSyXXXXXXXXXXXXXXXX
   VITE_FIREBASE_AUTH_DOMAIN=alkaabi-tech.firebaseapp.com
   VITE_FIREBASE_PROJECT_ID=alkaabi-tech
   VITE_FIREBASE_STORAGE_BUCKET=alkaabi-tech.appspot.com
   VITE_FIREBASE_MESSAGING_SENDER_ID=123456789
   VITE_FIREBASE_APP_ID=1:123456789:web:xxxxxxxx
   ```

### الخطوة 4: تثبيت المشروع وتجربته على جهازك

بمجلد المشروع، افتح Terminal واكتب:

```
npm install
npm run dev
```

راح يطلعلك رابط مثل `http://localhost:5173` — افتحه بالمتصفح، سجّل دخول بالبريد وكلمة المرور اللي سويتهم بالخطوة 2، وجرّب تنشئ طلب.

### الخطوة 5: رفع قواعد الأمان (Firestore Rules)

هذا مهم جداً — بدونه أي شخص يقدر يقرأ أو يعدّل بياناتك. سطّب أداة Firebase مرة وحدة:

```
npm install -g firebase-tools
firebase login
firebase use --add
```

اختر مشروعك اللي أنشأته بالخطوة 2. بعدين ارفع القواعد:

```
firebase deploy --only firestore:rules
```

### الخطوة 6: نشر الموقع أونلاين (Hosting)

```
npm run build
firebase deploy --only hosting
```

راح يعطيك رابط مثل `https://alkaabi-tech.web.app` — هذا رابط موقعك الحقيقي اللي تفتحه من أي جهاز أو جوال، وتقدر تثبته كتطبيق (PWA) من قائمة المتصفح "إضافة إلى الشاشة الرئيسية".

## الجزء الثاني: الاستخدام اليومي (سهل، بدون كود)

1. افتح رابط موقعك → سجّل دخول ببريدك وكلمة مرورك
2. اضغط **طلب جديد** بالأسفل → عبّي بيانات الزبون والجهاز → **حفظ الطلب**
3. بصفحة الطلب اضغط زر **QR** → اطبعه أو صوّره وأرسله للزبون (واتساب مثلاً)
4. أول ما يتغير وضع الجهاز، افتح الطلب وغيّر **الحالة** من القائمة — الزبون يشوف التحديث فوراً بصفحته
5. من **الرئيسية** تشوف عدد الطلبات الجديدة، قيد التنفيذ، المكتملة، والإيرادات والأرباح
6. من **الطلبات** تقدر تبحث بالاسم أو الهاتف أو رقم الطلب، وتفلتر حسب الحالة

الزبون ما يحتاج أي حساب أو تسجيل دخول — بس يفتح الرابط أو يمسح QR ويشوف حالة طلبه فقط.

## ملاحظات مهمة

- **الشعار**: حالياً فيه أيقونة مبدئية بسيطة (`public/icon-192.png` و`icon-512.png`) — إذا عندك شعار حقيقي للمحل، استبدل هذول الملفين بنفس الاسم والمقاس.
- **حساب ثاني للموظفين**: إذا احتجت مستقبلاً تعطي موظف صلاحية دخول، تضيفه من Authentication → Add user، والقواعد الحالية تسمح لأي حساب مسجّل دخول (كل الحسابات تعتبر أدمن حالياً). إذا تريد صلاحيات مختلفة بين الموظفين والمالك، خبرني نضيفها.
- **التوسع لاحقاً**: النظام مبني بشكل يسهل عليك تضيف WhatsApp API أو SMS أو تقارير محاسبية متقدمة بمرحلة ثانية بدون إعادة بناء كل شي.
